# Patricia Valladares-Ruiz — Academic Research Website

## Project goal

Build a static, elegant academic research website that communicates Patricia Valladares-Ruiz’s interdisciplinary humanities research program within the first few minutes of a visit. The site supports senior faculty applications, Research Chair applications, major grants, and international collaborations — without functioning as an online CV or generic faculty page.

## Target audiences

1. Senior faculty search committees
2. Research Chair committees
3. Major grant reviewers
4. International collaborators
5. Graduate students
6. Public humanities partners

## Design direction

Hybrid of museum exhibition, archival catalogue, academic publication, and Digital Humanities laboratory. Warm paper palette, deep ink typography, oxblood accents, editorial layout with numbered sections and generous whitespace. Bilingual orientation architected for future expansion; English-primary in v1.

## Scope constraints

- Static Next.js site, Vercel-ready
- No CMS, backend, database, authentication, or publication management system
- Projects-centered information architecture
- AI framed as extension of archives, metadata, and knowledge infrastructure work — not as engineering expertise
- Version 1 prioritizes job applications and August deadlines

## Technologies

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- next/font (Google Fonts)
- ESLint

Deferred to later phases: shadcn/ui, Framer Motion (subtle animations only when needed).

## What not to build

- CMS or admin interface
- Backend API or database
- User authentication
- Graph database or research platform
- Automated publication ingestion
- Complex animation or interactive dashboards

## August deadline priority

Phase 1 establishes architecture and design foundations. Subsequent phases deliver homepage, project pages, and content population in time for August application deadlines. Favor clarity and credibility over platform complexity.
